# Webon – Vulnerable Web Application

Webon is a deliberately vulnerable web application lab designed for learning and practicing **web application penetration testing**. The lab provides a controlled environment where common web vulnerabilities can be explored and exploited for educational purposes.

This project helps learners understand how attackers discover and exploit vulnerabilities and how secure coding practices can prevent them.

---

## Objectives

The main objectives of this lab are:

- Understand common **web application security vulnerabilities**
- Practice **manual web penetration testing**
- Learn how vulnerabilities are **identified and exploited**
- Gain hands-on experience with **security testing tools**
- Improve knowledge of **OWASP Top 10 security risks**

---

## Vulnerabilities Included

The lab contains intentionally vulnerable components that allow users to practice identifying and exploiting the following vulnerabilities:

- SQL Injection
- Cross-Site Scripting (XSS)
- Command Injection
- Insecure Direct Object Reference (IDOR)
- Cross-Site Request Forgery (CSRF)
- Authentication and session weaknesses
- Improper input validation

These vulnerabilities are implemented in a controlled manner to demonstrate real-world attack scenarios.

---

## Lab Environment

The lab is designed to run in a **safe and isolated environment** for security testing practice.

### Recommended Setup

- Kali Linux or any penetration testing environment
- Web browser (Firefox / Chrome)
- Burp Suite for interception and testing
- Local server or virtual lab environment

---

## Tools Used for Testing

The following tools can be used while practicing in this lab:

- Burp Suite
- Nmap
- Browser Developer Tools
- Kali Linux security utilities

These tools help in identifying vulnerabilities and analyzing how web applications behave during security testing.

---

## Learning Outcomes

After completing this lab, users will be able to:

- Identify common web vulnerabilities
- Understand the exploitation process used by attackers
- Perform basic web penetration testing
- Analyze insecure web application behavior
- Apply secure coding practices to prevent vulnerabilities

---

## Disclaimer

This project is intentionally vulnerable and created **for educational purposes only**.  
It should only be used in controlled environments for learning and security testing practice.
